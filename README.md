# 📊 Sales Performance Analysis of an E-commerce Company Using Exploratory Data Analysis

## 📌 Project Overview

This project was developed as part of the CodeAlpha Data Analytics Internship.

The objective is to analyze an e-commerce sales dataset using Python and Exploratory Data Analysis (EDA) techniques to identify trends, patterns, and business insights.

---

## 🎯 Objectives

- Explore the dataset structure
- Analyze sales and profit performance
- Identify top-performing categories and regions
- Visualize business trends
- Generate meaningful business insights

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

---

## 📂 Dataset

- Sample Superstore Dataset
- Records: 9,994
- Columns: 21

---

## 📈 Visualizations

1. Sales Distribution
2. Profit Distribution
3. Sales by Category
4. Sales by Region
5. Sales by Customer Segment
6. Profit by Category
7. Monthly Sales Trend
8. Top 10 Products by Sales
9. Top 10 States by Sales
10. Correlation Heatmap
11. Discount vs Profit Scatter Plot

---

## 💡 Key Business Insights

- Technology generated the highest sales.
- The West region achieved the highest sales.
- The Consumer segment contributed the highest revenue.
- California recorded the highest sales.
- Discount has a noticeable impact on profit.
